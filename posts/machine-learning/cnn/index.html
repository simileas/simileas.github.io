使用 Pytorch 处理 Minist 数据集的代码：

import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms

# 定义卷积神经网络
class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        # 生成第一个卷积层，输入通道数为1，输出通道数为32，卷积核大小为3x3，步幅为1，填充为1
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, stride=1, padding=1)
        # 池化层，使用2x2的最大池化，步幅为2，输出大小减半
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        # 生成第二个卷积层，输入通道数为32，输出通道数为64，卷积核大小为3x3，步幅为1，填充为1
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, stride=1, padding=1)
        # 全连接层，输入特征数为64*7*7，输出特征数为128
        self.fc1 = nn.Linear(64 * 7 * 7, 128)
        # 全连接层，输入特征数为128，输出特征数为10（对应10个类别）
        self.fc2 = nn.Linear(128, 10)
        # 激活函数
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.relu(self.conv1(x))
        x = self.pool(x)
        x = self.relu(self.conv2(x))
        x = self.pool(x)
        # 展平多维输入数据为一维
        x = x.view(-1, 64 * 7 * 7)
        x = self.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# 加载数据集
transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,))])
trainset = torchvision.datasets.MNIST(root='./data', train=True, download=True, transform=transform)
trainloader = torch.utils.data.DataLoader(trainset, batch_size=64, shuffle=True)

net = CNN()
# 损失函数，使用交叉熵损失
criterion = nn.CrossEntropyLoss()
# SGD 优化器，学习率为0.01，动量为0.9
optimizer = optim.SGD(net.parameters(), lr=0.01, momentum=0.9)

# 训练网络
for epoch in range(5):
    running_loss = 0.0
    for i, data in enumerate(trainloader, 0):
        inputs, labels = data
        optimizer.zero_grad()
        # 前向传播，获得输出
        outputs = net(inputs)
        # 计算损失，criterion 是交叉熵损失函数
        loss = criterion(outputs, labels)
        # 反向传播和优化
        loss.backward()
        # 更新参数
        optimizer.step()
        running_loss += loss.item()
        if i % 100 == 99:
            print(f'[Epoch {epoch + 1}, Batch {i + 1}] loss: {running_loss / 100:.3f}')
            running_loss = 0.0
print('Finished Training')

# 保存模型
torch.save(net.state_dict(), 'cnn_mnist.pth')

卷积神经网络中，每一个样本，都转换为特征与特征值的形式，在第一层卷积中，特征是边缘、角点等低级特征，特征值是这些特征在图像中的响应强度。

进入全连接层之前，通过卷积与池化，一个样本得到了多个特征及其对应的特征值；

那么每一个特征值，是标量，还是向量呢？

是标量。

因为每一个特征值，都是通过卷积核在图像上滑动计算得到的单一数值，表示该特征在图像中的响应强度。

我们无法准确的说出某个特征到底代表什么，也没办法说清楚特征值具体代表什么，但是我们知道，特征值越大，说明该特征在图像中越明显。

再回到例子中，第一次卷积，使用了 32 个卷积核，对输入图像进行卷积操作，输入图像是 1 个通道（灰度图），经过卷积操作后，得到了 32 个特征图，每个特征图对应一个卷积核提取的特征；

这 32 个卷积核，都是随机初始化的；

卷积核 3x3 的大小，意味着每次卷积操作时，步幅为 1，填充为 1，意思是卷积核在图像上滑动时，每次移动 1 个像素，并且在图像边缘补充 1 层像素，以保持输出特征图的尺寸与输入图像相同；

然后进行池化，将每个特征图的尺寸减半，保留了主要特征信息，同时减少了计算量；

接着，第二次卷积，输入通道数变为 32（上一次卷积的输出），使用了 64 个卷积核，提取更复杂的特征，得到 64 个特征图；

通道数可以理解为不同的特征维度，每个通道对应一种特征表示，灰度图只有一个通道，而彩色图像有三个通道（红、绿、蓝）。第二层输入的 32 个通道，表示有 32 种不同的特征表示，经过卷积操作后，得到 64 个通道，表示提取了更多种类的特征。

单色或者三原色比较容易理解，那么 32 通道、64 通道的图像，实际上这已经脱离了视觉的范畴，我们无法用肉眼去感知这些通道所代表的具体含义；但是可以看作对象的投影，不同的通道代表了对象在不同特征维度上的投影信息。

第二卷积的结果，再经过池化，尺寸再次减半，形成 64 个特征，每个特征是一个 7x7 的特征图；

特征图上的每一个特征点，是一个标量，这个标量是图片上的颜色值通过卷积核计算得到的响应值，然后经过激活函数处理后，得到一个 0 到 1 之间的数值，表示该位置上该特征的强度；

进入全连接层前，需要将这些特征图展平为一个一维向量，大小为 64 * 7 * 7 = 3136；也就是说，进入全连接层的输入特征和特征值的形式，是 3136 个特征，每个特征对应一个标量特征值。

全连接层的作用是将提取到的特征进行整合和分类。第一个全连接层将 3136 个输入特征映射到 128 个隐藏单元，第二个全连接层将 128 个隐藏单元映射到最终的 10 个输出类别。

映射方法是通过权重矩阵与输入向量的矩阵乘法实现的，每个隐藏单元或输出类别都有一组权重，表示该单元对输入特征的响应强度。

从 3136 个输入特征映射到 128 个隐藏单元，实际上是通过一个 128 x 3136 的权重矩阵与输入向量相乘，得到 128 个输出特征值，每个特征值是一个标量，表示该隐藏单元对输入特征的综合响应。

结合矩阵、权重、偏置，对应的数学表达式如下：

\[ h_j = f\left(\sum_{i=1}^{3136} w_{ji} x_i + b_j\right) \]

其中，\( h_j \) 是第 \( j \) 个隐藏单元的输出，\( w_{ji} \) 是连接输入特征 \( x_i \) 到隐藏单元 \( h_j \) 的权重，\( b_j \) 是隐藏单元的偏置，\( f \) 是激活函数。

经过两层全连接层后，最终输出 10 个类别的得分，每个得分是一个标量，表示该类别的预测概率。

然后通过反向传播算法，计算出最拟合训练数据的权重和偏置，从而完成模型的训练过程。

那么 pth 文件中保存的参数是什么样的呢？

可以通过以下代码查看保存的参数：

import torch
model = CNN()
model.load_state_dict(torch.load('cnn_mnist.pth'))
for name, param in model.named_parameters():
    if param.requires_grad:
        print(name, param.data)

可以看到全连接层 fc1 和 fc2 的权重矩阵和偏置向量，这个能够验证以上的推断，其中 fc1 的权重矩阵大小是 (128, 3136)，偏置向量大小是 (128,)；fc2 的权重矩阵大小是 (10, 128)，偏置向量大小是 (10,)。

为什么 fc1 的权重矩阵是 (128, 3136) 呢？因为 fc1 层有 128 个隐藏单元，每个隐藏单元连接了 3136 个输入特征，所以权重矩阵的行数是隐藏单元数，列数是输入特征数。计算时，输入向量的形状是 (3136, 1)，与权重矩阵 (128, 3136) 相乘，得到输出向量 (128, 1)。3136 与 128 向量乘，是得不到 128 向量的，必须是矩阵乘法，才能得到正确的结果。这里参数量还是挺大的，128 x 3136 = 401408 个权重参数，加上 128 个偏置参数，共计 401536 个参数。

全连接层的参数量通常比较大，因为每个输入特征都与每个隐藏单元相连接，导致权重矩阵的尺寸较大。这也是为什么在设计神经网络时，通常会在卷积层之后使用池化层来减少特征图的尺寸，从而降低全连接层的参数量和计算复杂度。

还记得卷积层的参数量吗？第一层卷积层 conv1 的参数量是 320 个，其中包含 32 个卷积核，每个卷积核有 3x3=9 个权重，加上一个偏置参数，共计 10 个参数，32 个卷积核总计 320 个参数。第二层卷积层 conv2 的参数量是 18496 个，其中包含 64 个卷积核，每个卷积核有 32 个输入通道，每个通道有 3x3=9 个权重，加上一个偏置参数，共计 32x9+1=289 个参数，64 个卷积核总计 64x289=18496 个参数。这些参数其实是用于提取图像特征的，相比全连接层，卷积层的参数量要少得多。

为什么卷积层还需要偏置呢？

如果一个输入的像素是纯黑色的，卷积核的权重和这个像素相乘，得到的结果可能是 0，如果没有偏置，那么这个卷积核在这个位置的输出就是 0，无法反映出该特征在图像中的存在。通过添加偏置，可以调整卷积核的输出，使其能够更好地捕捉图像中的特征信息。因此，偏置在卷积层中也是非常重要的，它有助于提高模型的表达能力和性能。

交叉熵损失函数
#

交叉熵损失函数（Cross Entropy Loss）是一种常用的损失函数，特别适用于分类问题。它衡量的是两个概率分布之间的差异，通常用于评估模型预测的概率分布与真实标签的概率分布之间的差异。

对于多分类问题，假设有 \( C \) 个类别，模型的输出是一个长度为 \( C \) 的向量，表示每个类别的预测概率。真实标签通常使用 one-hot 编码表示，即只有正确类别的位置为 1，其余位置为 0。

交叉熵损失函数的数学表达式如下：

\[ L = -\sum_{i=1}^{C} y_i \log(p_i) \]

其中，\( L \) 是损失值，\( C \) 是类别数，\( y_i \) 是真实标签的 one-hot 编码（如果样本属于类别 \( i \)，则 \( y_i = 1 \)，否则 \( y_i = 0 \)），\( p_i \) 是模型预测的类别 \( i \) 的概率。

通过独热编码，保留了属于类别 \( i \) 的那一项，其他项为 0，因此损失函数实际上只计算了正确类别的预测概率的对数。小数值的对数是负数，因此交叉熵损失值越小，表示模型预测的概率分布与真实标签的概率分布越接近。
